\doxysubsection{Detailed Description}
Service for calculating promotional discounts. 

This engine implements various promotion types including\+:
\begin{DoxyItemize}
\item THREE\+\_\+\+FOR\+\_\+\+TWO\+: Buy 3, pay for 2
\item BOGOF\+: Buy One Get One Free
\item FREE\+\_\+\+DELIVERY\+: Waive delivery charges (noted but not calculated here)
\item PERCENTAGE\+\_\+\+OFF\+: X\% discount
\item FIXED\+\_\+\+DISCOUNT\+: Fixed amount off
\end{DoxyItemize}

All calculations use Big\+Decimal for precision and round to 2 decimal places.
