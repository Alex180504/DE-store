Scheduled task to check stock levels and send alerts. 

This method runs automatically according to the cron expression configured in application.\+yml (default\+: every 6 hours at minute 0).

Workflow\+:
\begin{DoxyEnumerate}
\item Query warehouse DB for items below low stock threshold
\item Classify items by severity (out-\/of-\/stock, critical, low)
\item Query auth DB for active network manager emails
\item Send HTML email with grouped alerts
\item Log results and completion
\end{DoxyEnumerate}
