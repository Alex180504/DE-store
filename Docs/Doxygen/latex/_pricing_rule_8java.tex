\doxysubsection{Detailed Description}
JPA Entity representing a pricing rule. 

Pricing rules support hierarchical pricing with two levels\+:
\begin{DoxyItemize}
\item Global (is\+\_\+global=true, store\+\_\+id=null)\+: Network-\/wide pricing set by Network Manager
\item Store-\/specific (is\+\_\+global=false, store\+\_\+id!=null)\+: Per-\/store pricing set by Store Manager
\end{DoxyItemize}

Store-\/specific rules override global rules when calculating final prices. Rules can include promotions (3FOR2, BOGOF, etc.) and time-\/based validity.
