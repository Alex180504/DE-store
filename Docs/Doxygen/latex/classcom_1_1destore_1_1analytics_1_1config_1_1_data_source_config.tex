\doxysubsection{Detailed Description}
Multi-\/datasource configuration for analytics service. 

Configures read-\/only connections to\+:
\begin{DoxyItemize}
\item Accounting DB (primary data source for transactions)
\item Store DB (store metadata)
\item Warehouse DB (product metadata) 
\end{DoxyItemize}
