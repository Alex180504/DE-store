\doxysubsection{Detailed Description}
Service for managing pricing rules (CRUD operations) 

This service provides business logic for creating, reading, updating, and deleting pricing rules. It enforces validation rules and converts between entities and DTOs.

Responsibilities\+:
\begin{DoxyItemize}
\item Validate item exists in warehouse before creating rules
\item Validate store exists before creating store-\/specific rules
\item Convert between Pricing\+Rule entities and DTOs
\item Manage rule lifecycle (create, update, delete)
\end{DoxyItemize}
