\doxysubsection{Detailed Description}
Configuration for multiple database connections. 

Configures two datasources\+:
\begin{DoxyEnumerate}
\item Primary\+: Pricing Database (Postgre\+SQL) -\/ Read/\+Write for JPA
\item Secondary\+: Warehouse Database (My\+SQL) -\/ Read-\/\+Only for item validation
\end{DoxyEnumerate}

This allows the pricing service to validate items against the legacy warehouse database while managing its own pricing rules.
