Create a new pricing rule. 

Network Managers can create global rules (is\+\_\+global=true, store\+\_\+id=null). Store Managers can create store-\/specific rules (is\+\_\+global=false, store\+\_\+id set).

Validation\+:

\item Store must exist (if store-\/specific)
\item Global rules cannot have store\+\_\+id
\item Promotion value required for PERCENTAGE\+\_\+\+OFF and FIXED\+\_\+\+DISCOUNT
