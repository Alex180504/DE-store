\doxysubsection{Detailed Description}
REST controller for pricing rule management. 

This controller provides CRUD operations for pricing rules. Used by Store Managers (store-\/specific rules) and Network Managers (global rules) to configure pricing and promotions.

Endpoints\+:
\begin{DoxyItemize}
\item GET /api/pricing/rules -\/ List all pricing rules
\item GET /api/pricing/rules/\{id\} -\/ Get specific rule
\item GET /api/pricing/rules/item/\{item\+Id\} -\/ Get rules for item
\item GET /api/pricing/rules/store/\{store\+Id\} -\/ Get rules for store
\item GET /api/pricing/rules/active -\/ Get all active rules
\item POST /api/pricing/rules -\/ Create new pricing rule
\item PUT /api/pricing/rules/\{id\} -\/ Update existing rule
\item DELETE /api/pricing/rules/\{id\} -\/ Delete rule
\item POST /api/pricing/rules/\{id\}/deactivate -\/ Soft delete (deactivate)
\end{DoxyItemize}
