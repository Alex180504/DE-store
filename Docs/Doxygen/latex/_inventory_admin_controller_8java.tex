\doxysubsection{Detailed Description}
REST controller for inventory administration endpoints. 

This controller provides management APIs for Network Managers to\+:
\begin{DoxyItemize}
\item Trigger manual stock checks
\item View current stock alerts
\item Configure alert thresholds
\item Monitor inventory statistics
\end{DoxyItemize}

Security\+: All admin endpoints require JWT authentication with NETWORK\+\_\+\+MANAGER role. Role validation is enforced via @\+Pre\+Authorize annotations. Health check endpoint is public (no authentication required).

Endpoints\+:
\begin{DoxyItemize}
\item GET /api/inventory/health -\/ Public health check
\item POST /api/inventory/admin/trigger-\/check -\/ Manual stock check with email
\item GET /api/inventory/admin/alerts -\/ Current alerts (no email)
\item GET /api/inventory/admin/thresholds -\/ Get threshold configuration
\item PUT /api/inventory/admin/thresholds -\/ Update thresholds
\item GET /api/inventory/admin/stats -\/ Statistics dashboard data
\end{DoxyItemize}
