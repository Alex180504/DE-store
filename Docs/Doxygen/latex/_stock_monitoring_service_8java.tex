\doxysubsection{Detailed Description}
Service for monitoring warehouse stock levels and sending alerts. 

This service is responsible for the core inventory monitoring functionality\+:
\begin{DoxyItemize}
\item Scheduled stock level checks (default\+: every 6 hours)
\item Detection of low, critical, and out-\/of-\/stock items
\item Email notification to network managers
\item Manual trigger support for on-\/demand checks
\end{DoxyItemize}

The service reads from two databases\+:
\begin{DoxyItemize}
\item Warehouse DB (My\+SQL)\+: Item stock levels (read-\/only)
\item Auth DB (Postgre\+SQL)\+: Network manager email addresses (read-\/only)
\end{DoxyItemize}

Thresholds are dynamically configured via Inventory\+Config\+Service, allowing runtime updates without service restart.
