\doxysubsection{Detailed Description}
Exception thrown when a pricing rule is not found. 

This exception is raised when attempting to retrieve, update, or delete a pricing rule that doesn\textquotesingle{}t exist, or when no applicable pricing rule can be found for a given item/store combination.
