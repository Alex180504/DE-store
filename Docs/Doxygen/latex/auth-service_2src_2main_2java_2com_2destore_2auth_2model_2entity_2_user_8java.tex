\doxysubsection{Detailed Description}
JPA Entity representing a user in the auth service. 

Users can have one of two roles\+:
\begin{DoxyItemize}
\item NETWORK\+\_\+\+MANAGER\+: Manages global pricing rules (store\+\_\+id is null)
\item STORE\+\_\+\+MANAGER\+: Manages pricing rules for a specific store (store\+\_\+id is set)
\end{DoxyItemize}

Password storage uses BCrypt which automatically handles salt generation and storage within the hash itself.
