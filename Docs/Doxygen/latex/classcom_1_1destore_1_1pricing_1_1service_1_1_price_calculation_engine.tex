Calculate final price for an item with quantity and promotions. 

Algorithm\+:
\begin{DoxyEnumerate}
\item Validate item exists in warehouse
\item Find applicable pricing rule (store-\/specific or global)
\item Calculate subtotal = unit\+Price \texorpdfstring{$\ast$}{*} quantity
\item Calculate promotion discount
\item Calculate final price = subtotal -\/ discount
\item Return detailed breakdown
\end{DoxyEnumerate}

Hierarchical Rule Logic\+:
\begin{DoxyItemize}
\item If store\+Id is provided, search for store-\/specific rule first
\item If no store rule found, fallback to global rule
\item Store-\/specific rules (is\+\_\+global=false) override global rules (is\+\_\+global=true)
\end{DoxyItemize}
