\doxysubsection{Detailed Description}
Service for composing and sending stock alert emails. 

This service handles all email communication for the inventory monitoring system. It formats stock alerts into professional HTML emails and sends them to network managers via SMTP.

Features\+:
\begin{DoxyItemize}
\item HTML email formatting with color-\/coded severity levels
\item Grouped alerts by status (Out of Stock, Critical, Low)
\item XSS protection with HTML escaping
\item Configurable sender address and subject prefix
\item Enable/disable toggle for testing
\end{DoxyItemize}

Email Structure\+:
\begin{DoxyItemize}
\item Header with timestamp
\item Statistics summary
\item Tables grouped by severity (red/orange/yellow)
\item Footer with automated message disclaimer
\end{DoxyItemize}
