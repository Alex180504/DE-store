\doxysubsection{Detailed Description}
Service for managing inventory threshold configuration. 

This service provides runtime configuration management for stock alert thresholds. Thresholds determine when items are flagged as low, critical, or out of stock.

Current Implementation\+:
\begin{DoxyItemize}
\item In-\/memory storage (volatile -\/ resets on service restart)
\item Initialized from environment variables
\item Thread-\/safe updates with synchronized methods
\item Network managers can update via admin API
\end{DoxyItemize}

Configuration Parameters\+:
\begin{DoxyItemize}
\item low\+Stock\+Threshold\+: Items below this trigger LOW alerts (default\+: 50)
\item critical\+Stock\+Threshold\+: Items below this trigger CRITICAL alerts (default\+: 20)
\item out\+Of\+Stock\+Threshold\+: Items at this level trigger OUT\+\_\+\+OF\+\_\+\+STOCK alerts (default\+: 0)
\end{DoxyItemize}
