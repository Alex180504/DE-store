\doxysubsection{Detailed Description}
Core pricing calculation engine with hierarchical rule support. 

This engine implements the hierarchical pricing logic where store-\/specific rules override global (network-\/wide) rules. The calculation process\+:


\begin{DoxyEnumerate}
\item Validate item exists in warehouse database
\item Query for store-\/specific rule (if store\+Id provided)
\item If no store rule found, fallback to global rule
\item Apply promotion discounts using Promotion\+Engine
\item Return detailed price breakdown
\end{DoxyEnumerate}

The override logic ensures that Store Managers can set custom pricing that takes precedence over Network Manager\textquotesingle{}s global pricing.
