\doxysubsection{Detailed Description}
Main application class for Inventory Monitoring Service. 

This is the entry point for the inventory monitoring microservice. It enables scheduled tasks for automated stock level checking and email notifications to network managers.

Key Features\+:
\begin{DoxyItemize}
\item Multi-\/datasource configuration (Warehouse My\+SQL + Auth Postgre\+SQL)
\item Scheduled stock monitoring (configurable via cron expression)
\item Email notifications for low/critical/out-\/of-\/stock items
\item JWT-\/secured admin API for manual triggers and threshold management
\end{DoxyItemize}
