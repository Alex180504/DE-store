In July 2025, \href{https://c4model.com/}{\texttt{ https\+://c4model.\+com/}} introduced a new visual style for C4 diagrams. C4-\/\+Plant\+UML now supports this updated styling too.

To enable the new style, use one of these options\+:
\begin{DoxyItemize}
\item Add {\ttfamily !\+NEW\+\_\+\+C4\+\_\+\+STYLE=1} before including any C4\+\_\+\texorpdfstring{$\ast$}{*} files
\item Use the command line argument {\ttfamily -\/DNEW\+\_\+\+C4\+\_\+\+STYLE=1}
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
The {\ttfamily !\+NEW\+\_\+\+C4\+\_\+\+STYLE=1} statement must be placed BEFORE all C4\+\_\+ !include statements.
\end{DoxyWarning}

Similar to Plant\+UML themes supports C4-\/\+Plant\+UML {\ttfamily C4\+\_\+...} specific themes too (sometimes based on existing Plant\+UML themes).

Additional to the standard themes with skinparam and style definitions requires C4-\/\+Plant\+UML corresponding variable definitions. Therefore we started with the convention that all C4-\/\+Plant\+UML compatible themes start with {\ttfamily C4\+\_\+...} in the name (e.\+g. theme \href{https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/themes/puml-theme-C4_united.puml}{\texttt{ {\ttfamily C4\+\_\+united}}} bases on the \href{https://raw.githubusercontent.com/plantuml/plantuml/master/themes/puml-theme-united.puml}{\texttt{ {\ttfamily united}}} theme and contains all additional required C4-\/\+Plant\+UML settings that it can be directly used in all C4-\/\+Plant\+UML diagrams).

\begin{DoxyWarning}{Warning}
The !theme statement has to be BEFORE the !include statements.
\end{DoxyWarning}
E.\+g. in order to invoke theme {\ttfamily C4\+\_\+united} from a remote repository, you have to use the following directive\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{!theme\ C4\_united\ from\ https://raw.githubusercontent.com/plantuml-\/stdlib/C4-\/PlantUML/master/themes}

\end{DoxyCode}


In order to invoke a local theme {\ttfamily C4\+\_\+foo}, you have to use the following directive\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{!theme\ C4\_foo\ from\ /path/to/themes/folder}

\end{DoxyCode}


Starting with Plant\+UML v1.\+2023.\+8 the C4 themes can be invoked via C4-\/\+Stdlib or calculated paths too\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{'\ theme\ from\ C4-\/Stdlib}
\DoxyCodeLine{!theme\ C4\_united\ from\ <C4/themes>}
\DoxyCodeLine{}
\DoxyCodeLine{'\ another\ alternative:\ theme\ with\ calculated\ from}
\DoxyCodeLine{!RELATIVE\_INCLUDE\ =\ "{}https://raw.githubusercontent.com/plantuml-\/stdlib/C4-\/PlantUML/master"{}}
\DoxyCodeLine{!theme\ C4\_united\ from\ \%get\_variable\_value("{}RELATIVE\_INCLUDE"{})/themes}

\end{DoxyCode}
