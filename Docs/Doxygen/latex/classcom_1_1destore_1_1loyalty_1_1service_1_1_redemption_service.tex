\doxysubsection{Detailed Description}
Service for handling loyalty points redemption. 

Implements SAGA pattern for basket checkout with points redemption\+:
\begin{DoxyEnumerate}
\item Validate customer has sufficient points
\item Reserve points (pessimistic lock)
\item Calculate discounted prices
\item Commit transaction
\item Compensate on failure (refund points) 
\end{DoxyEnumerate}
